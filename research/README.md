# Research

This directory contains literature reviews, technical findings, and research hypotheses for OpenSubsurface.

The project remains in early research. The [first simulation pilot](../experiments/ert-observability-pilot/README.md) is implemented, with an inconclusive numerical run and no completed geometry bank or field validation.

| [Recommended direction](recommended-direction.md) | Scoped adaptive ERT hypothesis and decision criteria |

The numerical experiment targets are proposed thresholds. They are not results or an approved implementation scope.

Every document must distinguish established findings, proposed hypotheses, speculation, and project results. External demonstrations are not OpenSubsurface results.
